# 🪷 Indian Mythology Daily Digest

A daily HTML field note exploring stories, characters, and verses from the **Mahabharata**, **Ramayana**, **Bhagavad Gita**, and **Puranas**. Each day features a new article with:

- 📖 **The Story** — Full narrative of an episode or character moment
- 🧠 **Why It Matters** — Insightful commentary and analysis
- 💡 **Today's Lesson** — Practical wisdom to apply in daily life
- 🤔 **Reflect On This** — A personal reflection question
- 🪷 **Sanskrit Shlokas** with transliteration and translation (from Bhagavad Gita)
- 🖼️ **Illustrations** from Wikimedia Commons
- 💬 **An uplifting quote** to carry through the day
